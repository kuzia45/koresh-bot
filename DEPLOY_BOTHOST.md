# Запуск Кореша на Bothost из приватного GitHub

Репозиторий: https://github.com/kuzia45/koresh-bot

Бот Telegram: https://t.me/Poker_Empire_1_bot

Владелец Telegram: `379721932`. Имя персонажа по умолчанию: `Кореш`.

## 1. Получить Telegram-токен

В Telegram открыть проверенного **@BotFather**, отправить `/mybots`, выбрать
**@Poker_Empire_1_bot** и открыть **API Token**. Скопировать существующий токен.
Он вводится только в поле токена на Bothost. В код и GitHub его не добавлять.
Если этот бот уже работает где-то ещё, остановить старую программу до запуска
новой: один Telegram-токен должен обслуживать один экземпляр программы.

## 2. Дать Bothost чтение приватного репозитория

Приватный репозиторий Bothost не сможет скачать по одной только ссылке.
Нужен отдельный GitHub-токен на чтение:

1. На GitHub открыть аватар → **Settings** → **Developer settings** →
   **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
   Прямая ссылка: https://github.com/settings/personal-access-tokens/new
2. Название: `Bothost koresh-bot`. Указать удобный срок действия.
3. **Resource owner**: `kuzia45`.
4. **Repository access** → **Only select repositories** → **koresh-bot**.
5. **Repository permissions** → **Contents** → **Read-only**. Metadata может
   добавиться автоматически; остальные права не нужны.
6. Создать токен и скопировать его. Полное значение показывается один раз.
7. Открыть https://bothost.ru/admin-repos.php — **Git репозитории**.
8. Заполнить форму подключения:

| Поле | Значение |
|---|---|
| URL репозитория | `https://github.com/kuzia45/koresh-bot.git` |
| Ветка | `main` |
| Способ доступа | HTTPS — логин/пароль или токен |
| Username | `x-access-token` |
| Пароль/Токен | Новый GitHub-токен из шага 6 |

9. Нажать **Сохранить**. Дождаться успешного подключения, если панель
   показывает результат проверки.

Telegram-токен и GitHub-токен — два разных значения для разных полей.

## 3. Создать бота на Bothost

Открыть https://bothost.ru/create-bot.php и заполнить:

| Поле | Значение |
|---|---|
| Название | `Кореш` |
| Платформа | Telegram |
| Язык | Python |
| Bot Token | Telegram-токен от @BotFather |
| Локация | Нидерланды, если этот выбор доступен |
| Git URL | `https://github.com/kuzia45/koresh-bot.git` |
| Ветка | `main` |
| Описание | Кореш для группы друзей, агент Codex по подписке |

Локация должна иметь доступ к сервисам OpenAI. Проверим его фактическим
входом на следующем этапе.

В **Дополнительных настройках**:

- Включить **Использовать собственный Dockerfile**. Это обязательно: внутри
  устанавливается Codex CLI. Если интерфейс предлагает отдельный стек
  **Dockerfile**, выбрать его.
- Главный файл, если поле есть: `bot.py`.
- Веб-интерфейс/домен не обязателен: бот получает сообщения через long polling.
  Если веб-интерфейс включён, внутренний порт — `8080`; проверка — `/health`.

В переменных окружения удобно явно указать:

```dotenv
OWNER_ID=379721932
BOT_NAME=Кореш
BOT_ALIASES=кореш,корешок
DATA_DIR=/app/data
CODEX_HOME=/app/data/codex
PORT=8080
```

Первые, четвёртая, пятая и шестая переменные уже заданы в Dockerfile;
повторное указание в панели необязательно. Bothost сам создаёт `BOT_TOKEN`
из заполненного поля Telegram-токена. Модель можно оставить по умолчанию.

Нажать **Создать бота**. Дождаться окончания сборки и статуса **Работает**.
В логах должна появиться строка `Bot connected` и сообщение об ожидании `/login`.

## 4. Подключить текущую подписку Codex

1. Со своего Telegram-аккаунта открыть https://t.me/Poker_Empire_1_bot.
2. Нажать **Запустить** и отправить `/login`.
3. Бот пришлёт https://auth.openai.com/codex/device и одноразовый код.
4. Открыть ссылку в браузере, войти в тот аккаунт OpenAI, где есть подписка,
   ввести код и завершить вход.
5. Дождаться сообщения бота **«Готово, вошёл через подписку»**.
6. Отправить `/status`. Ожидаемый результат: **«Codex по подписке: вход выполнен»**.
7. Написать: **«Кореш, скажи что-нибудь»**. Это проверит реальный запрос.

Если OpenAI сообщает, что вход по коду выключен, включить **Device code login**
в настройках безопасности ChatGPT и повторить `/login`. Пароль от OpenAI
в Telegram или Bothost вводить не нужно. API-ключ OpenAI также не нужен.

## 5. Добавить в группу друзей

1. В **@BotFather** отправить `/setprivacy`.
2. Выбрать **@Poker_Empire_1_bot** → **Disable**.
3. Добавить бота в нужную группу. Если он уже был добавлен, удалить и добавить
   снова, чтобы изменение Privacy Mode применилось. Администратором делать
   необязательно.
4. В группе со своего аккаунта отправить:

```text
/allow@Poker_Empire_1_bot
```

5. После подтверждения написать:

```text
Кореш, знакомься с бандой!
```

Можно также отвечать на его сообщения или обращаться через `@Poker_Empire_1_bot`.
Настоящее имя бота в профиле Telegram и рабочее имя персонажа — разные настройки.

## 6. Проверить память и мемы

В группе написать владельцем:

```text
/remember По пятницам играем в настолки
```

Файл с памяткой находится на Bothost в `/app/data/chats/ID_ГРУППЫ/memory.md`.
В чат бот этот файл не выгружает; команды для скачивания памяти нет.
После обычных разговоров бот сам дополняет долгосрочную память.

Для мемов: написать **«Кореш, скинь мем про котов»** или `/meme коты`.
Бот должен найти готовую картинку в интернете и прислать её со ссылкой
на источник. Никаких предварительных загрузок и сохранений не требуется.

Для ежедневного розыгрыша: участникам достаточно написать любое сообщение
в группе. Проверить список — `/pidormembers`. Telegram не позволяет боту
получить всех существующих участников разом, поэтому молчуна можно добавить
через `/pidoradd` ответом на его сообщение (команда владельца). Для актуальных
событий входа/выхода полезно дать боту права администратора. Перед выбором
бот также проверяет, не вышел ли участник.

Нужно хотя бы два участника. `/pidor` запускает сегодняшний выбор или
повторно показывает уже выбранного человека. `/pidorstats` — статистика.
Расписание по умолчанию — каждый день в 12:00 по Москве; изменить:
`/pidortime 21:00`. Розыгрыш работает без авторизации Codex и не расходует
его лимиты. Перезапуск не перевыбирает победителя.

`/quiet` оставляет ответы на обращения, но отключает самостоятельные реплики;
`/chatty` включает их обратно. Любой участник может написать `/noroast`,
чтобы отключить подколы над собой и исключить себя из розыгрыша. Команда
`/pidorleave` исключает только из розыгрыша.

## 7. Обновлять код из GitHub

Код сервера берётся из ветки **main** этого приватного репозитория. После
публикации нового коммита можно нажать **Обновить из Git** в карточке бота Bothost.
Память и авторизация сохраняются в `/app/data` и не хранятся в GitHub.

Для автоматического обновления после push:

1. На Bothost в карточке созданного бота открыть **Автообновление**
   (иконка молнии) и скопировать предоставленный **Webhook URL**.
2. На GitHub открыть репозиторий → **Settings** → **Webhooks** → **Add webhook**.
3. **Payload URL** — ссылка из Bothost.
4. **Content type** — `application/json`.
5. Если Bothost выдал отдельный **Secret**, указать ровно его.
6. Выбрать **Just the push event**, оставить **Active**, сохранить.
7. После следующего push проверить **Recent Deliveries** в GitHub и логи
   развёртывания Bothost. Ветка бота должна оставаться `main`.

Webhook для обновления из GitHub — это отдельная настройка от Telegram webhook.
Для сообщений Telegram наш бот использует long polling.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `Repository not found`, `Authentication failed` | GitHub-токен относится к `koresh-bot`, имеет Contents: Read-only, не истёк и сохранён в Git репозиториях Bothost |
| `Codex CLI не установлен` | При сборке использован собственный Dockerfile |
| `401` Telegram | Правильно скопирован Telegram-токен |
| `409` Telegram | Нет второй запущенной программы с тем же Telegram-токеном |
| Бот работает в личке, в группе молчит | Выполнены Disable Privacy Mode, повторное добавление и `/allow` от владельца |
| `/login` не проходит | Включён Device code login и из региона хостинга доступен OpenAI |
| `/status` успешен, обычный ответ не приходит | Логи, лимиты подписки, доступность модели по умолчанию |
