# 2.0.0 — 28 ноября 2026

## Готовые мемы из интернета

Больше не требуется сохранять картинки и подписи, чтобы бот мог отправить мем.
Он ищет готовые изображения на Memepedia и получает русскоязычные картинки
из Pikabu через публичный Meme API. Регистрации и платного API-ключа не нужно.
Можно попросить обычной фразой, а `/meme [тема]` работает вообще без ИИ.
В ответ приходит фото или GIF со ссылкой на источник, а не инструкция по
добавлению мема. Бот помнит последние 100 отправленных URL на чат.

Тематический поиск зависит от наличия подходящих готовых изображений
и доступности источников. Если совпадений нет, бот сообщает об этом,
а не подменяет запрос случайной картинкой. Reddit-публикации с NSFW и
spoiler-флагами отбрасываются. Старые сохранённые мемы остаются в БД;
скрытая команда `/savedmeme` оставлена для совместимости.

## Характер и память

Персонаж теперь передаётся через `developer_instructions` Codex: разговорная
короткая речь, мат без звёздочек по ситуации, отсутствие обязательного
панчлайна, запрет возвращать любую тему к старому внутреннему приколу.
В контексте слова человека и ответы бота имеют разные роли. Старые ответы
бота ограничены тремя сообщениями, а восемь последних реплик отдельно
передаются как список того, что нельзя повторять. Почти дословный повтор
вызывает одну попытку переписать ответ, если позволяет лимит запросов.

При первом старте этой версии прежняя автоматически собранная память
переносится в таблицу `memory_archive` внутри `/app/data/koresh.db`, затем
бот начинает собирать её заново из фактов, явно сообщённых людьми.
Его прежние ответы удаляются из короткого контекста. Команды `/remember`,
переписка людей, авторизация и остальные данные сохраняются. Миграция
выполняется один раз и не повторяет очистку после следующего рестарта.
Это убирает возможную петлю, когда бот запоминал собственные шутки.

## Пидор дня

- Равновероятный случайный выбор, без ИИ. Результат один на чат и дату.
- По умолчанию ежедневно в 12:00 по Москве; настраивается `/pidortime`.
- `/pidor` показывает победителя сегодня; повторная команда не перевыбирает.
- `/pidorstats` — число побед каждого человека за всё время.
- `/pidormembers` — список участников. `/pidorjoin` и `/pidorleave` — участие.
- Владелец может добавить молчуна командой `/pidoradd` в ответ на его сообщение.
- `/pidoron` и `/pidoroff` управляют автоматическими публикациями.
- Боты, вышедшие люди, `/noroast` и отказавшиеся от игры исключены.
- Для старта нужны минимум два участника.
- Выбор и статистика сохраняются до отправки: повторная попытка доставки
  не меняет победителя и не добавляет лишнюю победу.

Telegram Bot API не предоставляет выгрузку всех участников группы. Список
собирается из сообщений, событий вступления/выхода и `/pidoradd`.
Для получения `chat_member`-событий бот должен быть администратором;
прямые сообщения участников регистрируются и без этих прав. Перед
розыгрышем бот проверяет статус известных ему участников через getChatMember.
Надёжная проверка других участников гарантируется Telegram при правах
администратора. При сетевой ошибке выбор откладывается.

## Установка обновления

Нажать **Обновить из Git** на Bothost и дождаться пересборки по Dockerfile.
В `/status` или `/settings` должна появиться версия **2.0.0**.
Авторизация Codex и данные остаются в `/app/data`. После обновления всем
участникам достаточно написать в группе, затем проверить `/pidormembers`.
